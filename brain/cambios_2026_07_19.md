## 2. Lookup de inscripción por credenciales

### Requerimiento
Buscar la inscripción de un usuario en un evento/formulario específico usando credenciales (email + password). Si tiene inscripción devuelve los datos de la inscripción, si no tiene devuelve solo los datos de la persona.

### Archivos creados
| Archivo | Descripción |
|---------|-------------|
| `app/Http/Requests/LookupRegistrationRequest.php` | Validación: email, password, evento_id, form_type_id |

### Archivos modificados
| Archivo | Cambio |
|---------|--------|
| `routes/api.php` | Ruta `POST /registrations/lookup` |
| `app/Services/RegistrationService.php` | Método `lookupRegistration()` |
| `app/Http/Controllers/RegistrationController.php` | Método `lookup()` + import `LookupRegistrationRequest`, `PersonaResource` |

### Funcionamiento
- **Entrada:** `{ email, password, evento_id, form_type_id }` (todos obligatorios)
- **Autenticación:** Valida email + password contra tabla `personas`
- **Búsqueda:** Busca Registration por `evento_id` y `form_types_id` donde la persona sea participante (match por `numero_documento` o `correo`)
- **Respuesta tipo `"registration"`:** Si encuentra inscripción, devuelve datos completos con totales y participantes
- **Respuesta tipo `"persona"`:** Si no encuentra inscripción, devuelve datos de la persona con contacto de emergencia **y genera un token de autenticación** (funciona como login)
- **Error 401:** Si credenciales son inválidas

### Canales de notificación
- **mail** — Envío de correo via SMTP (configurable en `.env`)
- **database** — Almacenamiento en tabla `notifications` para lectura vía API
- **WhatsApp** — Envío via OpenWA SDK (reutiliza `SendWhatsappMessageJob` existente)

### Notificacións y sus canales
| Notificación | mail | database | WhatsApp |
|-------------|------|----------|----------|
| Registro creado | Sí | Sí | Sí |
| Pago confirmado | Sí | Sí | Sí |
| Registro cancelado | Sí | Sí | No |
| Código promocional | No | Sí | Sí |
| Recordatorio evento | Sí | Sí | Sí |
| Pago pendiente | Sí | Sí | Sí |

### Jobs programados
- `SendEventReminderJob` — Diario a las 09:00, busca eventos en `EVENT_REMINDER_DAYS` días
- `SendPendingPaymentJob` — Diario a las 08:00, busca registros pendientes en `PENDING_PAYMENT_REMINDER_DAYS` días
- Usa `pending_payment_notified_at` para no reenviar avisos

```env
NOTIFICATION_WHATSAPP_ENABLED=true

PENDING_PAYMENT_REMINDER_DAYS=3

```
